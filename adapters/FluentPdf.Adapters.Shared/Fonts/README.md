# Embedded fonts

These are the **Liberation Sans** fonts, licensed under the **SIL Open Font License (OFL)**.
They are metric-compatible with Arial/Helvetica and are embedded so the QuestPDF and iText
adapters render text with identical glyph metrics (consistent line-breaking and pagination).

Liberation fonts are © Red Hat, Inc., distributed under the SIL OFL — free to use, embed and
redistribute. See <https://github.com/liberationfonts/liberation-fonts>.
